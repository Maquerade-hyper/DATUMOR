# DATUMOR v0.1.0

First public release of DATUMOR.

DATUMOR is an open-source data intelligence and preparation engine
for ingesting, processing, validating and preparing data for AI workflows.

## Features
- Multi-format data ingestion
- Document and repository processing
- Data validation and quality checks
- AI-ready dataset preparation
- API and worker architecture
- Docker-based deployment
